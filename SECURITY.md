# Reporting a security problem

Please do not open a public issue for a vulnerability.

Report it privately, either through GitHub's private vulnerability reporting — the "Report a vulnerability" button
on this repository's Security tab — or by e-mail to security@nthcase.com.

Tell us what you found, how to reproduce it, and which version you used: the first line `--version` prints. We will
acknowledge your report within 3 working days and tell you what we will do and when. Please give us 90 days, or until
a fix is released, before you disclose it.

In scope: this agent, and how it talks to farm.nthcase.com. Out of scope: Appium, adb, Xcode and the other programs
the agent drives, and your own Appium configuration.

We support the latest release only. Upgrade by running the agent with `@latest` after its package name, as the
README shows.
