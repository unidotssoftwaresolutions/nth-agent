# nth-agent

This package is not the NthCase agent. It holds the name so that nobody else can publish under it.

The agent is published as **nthcase-agent**. Run it with `@latest` after its name, so that the newest release runs, and
not a copy already on the machine, however old:

```
npx nthcase-agent@latest --version
```

Running this package does nothing except print that line and exit with an error.
